# Public Keyword and Discovery Index

This board is a navigation layer for publicly accessible N.U-related works, independent creators, learners, references, and source pages. It is not a content archive, endorsement list, or statement of official N.U status.

## Listing rules

- Add only public URLs that were checked and are appropriate to share.
- Use neutral, descriptive keywords; do not imply N.U endorsement or Canon status.
- Link to the creator's authorized page or the primary source. Do not mirror full works.
- Attribute creators only when attribution is verifiable and appropriate.
- Keep private contact details, personal data, credentials, private drafts, and unreviewed claims out.
- A keyword is a discovery aid, not evidence that two works are equivalent.
